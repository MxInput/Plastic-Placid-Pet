## Plastic Placid Pet

A desktop pet for Windows where you can pick between one of six ducks to be active at any one time.
Inspired by Plastic Placid Duck Simulator

### Ducks Avaliable
- Mother Duck
    - Has a baby duck that follows them around
    - Push with the mouse to move
- Toot Duck
    - Plays trumpet sounds after a random interval
    - Push with the mouse to move
- Wizard Duck
    - Teleports after a certain interval
- Cat Duck
    - Follows the mouse
- Rock Duck
    - Moves slowly
    - Push with the mouse to move
- Big Duck
    - Moves quickly
    - Push with the mouse to move
 
**Use CTRL + I to swap between ducks**

### Installation Instructions
1. Download this repo
2. Install Godot from https://godotengine.org/download/windows/
3. Import the folder the repo is in into Godot to begin editing.
